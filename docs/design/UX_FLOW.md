# Luồng sử dụng

1. Mở trang Phân tích website. Trạng thái thu thập nằm ở masthead; API và worker có trạng thái riêng khi gặp lỗi.
2. Nhập URL. Full Scan được chọn sẵn khi worker sẵn sàng. Chọn Quick Scan nếu chỉ muốn phân tích địa chỉ. Chọn Snapshot Analysis để dán HTML hoặc chọn tệp.
3. Bấm Phân tích hoặc Enter trong ô URL. Khi đang chờ phản hồi, giao diện mô tả công việc đang yêu cầu. API chỉ cung cấp thời gian thực sau khi hoàn tất.
4. Đọc kết luận ngay dưới biểu mẫu, sau đó xem điểm, ngưỡng, phương pháp, thời gian và dấu hiệu. Khi trang không trả HTML, đọc lý do chuyển nhánh và số đặc trưng thực sự được dùng.
5. Mở Báo cáo phân tích để xem lại kết quả trong phiên. Khi chạy yêu cầu mới, kết quả cũ được gỡ khỏi vùng báo cáo để tránh gán nó cho yêu cầu lỗi.
6. Mở Hiệu năng mô hình để xem tập Test của primary. Mở Hướng dẫn để so sánh các chế độ và đọc giới hạn nghiên cứu.
