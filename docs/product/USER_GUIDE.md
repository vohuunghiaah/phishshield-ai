# Sử dụng PhishShield AI

Mở **Phân tích website**, nhập `https://example.org/` và bấm **Phân tích**. Khi dịch vụ thu thập sẵn sàng, Full Scan tự tải HTML tĩnh và dùng 34 đặc trưng. Quick Scan chỉ xử lý URL với 17 đặc trưng. Chọn **Snapshot Analysis (nâng cao)** để dán HTML đã lưu hoặc tải tệp UTF-8 (tối đa 8 MiB).

Đọc URL, kết luận và điểm so với ngưỡng ngay dưới biểu mẫu. Nếu Full Scan phải chuyển sang phân tích URL, báo cáo ghi rõ nguyên nhân. Mở **Chi tiết kỹ thuật** để xem checkpoint và đóng góp gốc. **Báo cáo phân tích** giữ lần phân tích gần nhất trong phiên. **Hiệu năng mô hình** trình bày tập Test của mô hình chính.
